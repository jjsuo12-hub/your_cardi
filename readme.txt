Your_Cadi 앱 가이드
===================

1. 앱 개요
----------
Your_Cadi는 병동 간호사가 HiCardi 적용 대상 환자를 등록하고, 시연용 더미 생체정보를 확인하며, 초기 세팅 절차와 간단 매뉴얼, Q&A를 빠르게 참고할 수 있도록 만든 Expo 기반 프로토타입 앱입니다.

이 앱은 실제 HiCardi 기기, EMR, 병원 서버와 연동되지 않습니다. 환자 현황과 생체정보 화면의 값은 모두 시연용 더미 데이터이며 실제 환자 데이터가 아닙니다. 앱 화면의 체크리스트, 매뉴얼, Q&A 내용도 임시안이며 실제 임상 판단이나 진단, 처방, 응급 판단에 사용할 수 없습니다.


2. 주요 화면 구성
----------------
앱은 하단 탭으로 이동합니다.

- 환자등록
- 환자 현황
- 초기 세팅
- 매뉴얼
- Q&A


3. 환자등록
-----------
환자등록 탭에서는 HiCardi 적용 대상으로 시연할 환자를 등록하거나 수정할 수 있습니다.

입력 항목:
- 환자명
- 병실
- 침상
- 진료과/환자 대분류
- 이식혈관외과 세부 항목
- POD
- 전동 출처
- 적용 사유
- 메모
- 환자별 Target 설정

진료과/환자 대분류:
- 이식혈관외과
- 소아외과
- 간담췌외과
- 위장관 외과
- 내분비 외과
- 기타 / 타과 중환자실 전동

이식혈관외과를 선택한 경우에만 세부 항목으로 간이식 또는 신장이식을 선택할 수 있습니다. 폐이식과 심장이식은 병동 대상 환자가 아니므로 선택지에서 제외되어 있습니다.

전동 출처:
- 병동 입원
- 수술실
- 중환자실
- 타과 중환자실
- 기타

등록된 환자는 환자 리스트에 표시됩니다. 리스트에서 환자를 누르면 기존 정보가 폼에 채워지고 수정 모드로 전환됩니다. 수정 저장 또는 취소를 선택할 수 있습니다.

환자별 Target 설정:
- HR min / max
- SpO2 min / max
- RR min / max
- Skin Temperature min / max

Target 값은 프로토타입 시연용 설정입니다. 실제 임상 기준으로 사용하지 마세요.

기존 적용 기준 체크리스트는 삭제하지 않고 "적용 기준 체크리스트 - 추후 확정 예정" 섹션으로 임시 유지되어 있습니다. 체크리스트 점수와 결과 문구는 임시 기준입니다.


4. 환자 현황
------------
환자 현황 탭에서는 등록된 환자들의 시연용 상태를 카드 형태로 확인합니다.

주요 기능:
- 등록된 환자 목록 표시
- 환자 카드 클릭 시 상세 패널 펼침/접힘
- HR, SpO2, RR, Skin Temperature 숫자 카드 표시
- 환자별 Target 기준에 따른 데모 이상 항목 강조
- ECG 더미 애니메이션 그래프 표시
- Vital Signs History 라인그래프 표시
- 그래프 hover/tap tooltip 표시
- 배터리와 신호 상태 등 시연용 정보 표시

상단에는 더미 데이터 안내 문구가 표시됩니다. 모든 생체정보는 실제 환자 데이터가 아니라 프로토타입 시연용 가상 데이터입니다.


5. 개발용 데모 이상 징후
------------------------
환자 현황 화면에는 "개발용 데모 이상 징후 데이터 생성" 토글이 있습니다.

토글 ON:
- 무작위 두 환자에게 데모 이상 징후 데이터가 적용됩니다.
- 환자 이름 영역이 붉게 깜빡일 수 있습니다.
- 이상 수치 항목이 강조됩니다.
- 알림 문구는 "환자 상태를 확인하세요"로 표시됩니다.

토글 OFF:
- 생체정보가 정상 더미 데이터로 복귀합니다.
- 모든 환자별 알림 억제 상태가 초기화됩니다.

"확인했습니다" 버튼:
- 해당 환자의 깜빡이는 데모 알림을 10분간 중지합니다.
- 알림 억제는 환자별로만 적용됩니다.
- 10분 후에도 이상 수치가 유지되면 다시 알림이 표시될 수 있습니다.

이 기능은 개발용 데모 기능입니다. 실제 환자 데이터가 아니며 임상 판단에 사용할 수 없습니다.


6. 초기 세팅
------------
초기 세팅 탭은 HiCardi 적용 전 확인 절차를 단계별 체크리스트로 보여줍니다.

예시 단계:
- 환자 확인
- 환자등록 정보 확인
- 피부 상태 확인
- 기기 번호 확인
- 기기 배터리 확인
- 패치 부착
- 환자-기기 매칭
- EKG / HR / RR 표시 확인
- 알람 상태 확인
- 적용 시작 시간 기록

모든 항목을 체크하면 세팅 완료 버튼이 활성화됩니다. 세팅 완료 시 시연용 환자가 환자 현황에 추가됩니다.

초기 세팅 안내는 임시안입니다. 실제 사용 시 제조사 지침과 병동 프로토콜을 우선 확인해야 합니다.


7. 매뉴얼
--------
매뉴얼 탭에서는 HiCardi 사용과 관련된 임시 매뉴얼 항목을 카드 형태로 확인할 수 있습니다.

주요 기능:
- 매뉴얼 검색
- 즐겨찾기
- 매뉴얼 상세 보기

예시 항목:
- 환자 등록 방법
- 기기 연결 확인 방법
- EKG 신호 확인 방법
- 알람 확인 방법
- 배터리 확인 방법
- 패치 재부착 또는 교체 시 확인사항
- 적용 종료 및 기기 회수 방법
- 인계 시 확인할 내용

모든 매뉴얼 내용은 임시안이며 추후 병동 지침과 제조사 지침에 맞게 수정되어야 합니다.


8. Q&A
-----
Q&A 탭에서는 작동 이상 상황을 선택하고 임시 문제 해결 순서를 확인할 수 있습니다.

예시 항목:
- EKG 신호가 보이지 않아요
- HR 값이 평소와 다르게 보여요
- RR 값이 표시되지 않아요
- 알람이 계속 떠요
- 환자 목록에 나타나지 않아요
- 기기 배터리가 부족해요
- 패치가 떨어졌어요
- 연결이 끊어졌어요
- 적용 종료는 어떻게 하나요?

Q&A 답변은 환자 상태 확인, 기기 상태 확인, 관리자 문의 순서의 참고용 흐름입니다. 실제 대응은 제조사 지침과 병동 프로토콜을 따릅니다.


9. 웹 실행 및 빌드
-----------------
개발 서버 실행:

  npm run web

웹 정적 빌드:

  npm run build:web

빌드 결과는 dist 폴더에 생성됩니다.

로컬에서 dist 확인:

  npm run serve:dist

기본 주소:

  http://127.0.0.1:8080


10. Vercel 배포
---------------
Vercel 설정 파일은 vercel.json입니다.

설정 요약:
- buildCommand: npm run build:web
- outputDirectory: dist
- devCommand: npm run web
- SPA 라우팅을 위해 모든 경로를 "/"로 rewrite

GitHub 저장소를 Vercel에 연결하면 main 브랜치 push 후 Vercel에서 Expo Web 빌드를 실행하고 dist 폴더를 배포합니다.


11. 안전 고지
-------------
이 앱은 간호관리학 SD 프로젝트 발표 및 프로토타입 시연용 앱입니다.

주의:
- 실제 의료기기 연동 앱이 아닙니다.
- 실제 환자 데이터를 표시하지 않습니다.
- 실제 환자 개인정보를 저장하지 않는 것을 전제로 합니다.
- 체크리스트와 매뉴얼은 임시안입니다.
- 실제 임상 판단, 진단, 처방, 응급 판단에 사용할 수 없습니다.
- 실제 적용 전 병동 프로토콜, 제조사 지침, 의료진 검토가 필요합니다.
