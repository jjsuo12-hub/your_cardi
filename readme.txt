Your_Cadi Main App Guide
========================

1. 개요
-------
Your_Cadi는 병동 간호사가 HiCardi 적용 판단 흐름을 시연하고, 적용 환자 현황, 초기 세팅, 간단 매뉴얼, Q&A를 한 화면 구조 안에서 확인할 수 있도록 만든 Expo 기반 프로토타입 앱입니다.

이 앱은 실제 HiCardi 기기, 실제 EMR, 병원 서버와 연동되지 않습니다.
앱에 표시되는 환자 정보와 생체정보는 모두 시연용 더미 데이터이며, 실제 의료 판단이나 실제 임상 처방을 대체하지 않습니다.


2. 현재 탭 구성
---------------
앱은 하단 탭 기반으로 동작합니다.

- 적용 기준
- 적용 환자 현황
- 초기 세팅
- 간단 매뉴얼
- Q&A


3. 적용 기준
------------
적용 기준 탭은 환자 검색, NEWS2 평가, 병동 특수 기준 확인, HiCardi 적용 여부 상의 결과 확인까지의 흐름을 제공합니다.

주요 기능:
- 환자번호 검색
- 더미 EMR 환자 정보 요약 확인
- 최근 활력징후 기반 NEWS2 자동 계산
- 병동 특수 적용 기준 선택
- 응급상황 시 의료진 상의 흐름 표시
- HiCardi 적용 여부 상의 결과 카드 표시
- 평가 기록 저장
- 적용 상의 대상으로 저장

표시 내용:
- NEWS2 총점
- NEWS2 점수 구간
- 병동 특수 적용 기준
- 결과 설명
- 다음 재평가 문구
- 평가 기록 이력

주의:
- 결과는 간호사 단독 결정이 아니라 담당 의료진과 상의하기 위한 참고용 시연 결과입니다.
- NEWS2 계산 결과와 병동 특수 기준은 실제 임상 프로토콜 확정본이 아닙니다.


4. 적용 환자 현황
-----------------
적용 환자 현황 탭은 현재 HiCardi 적용 중인 시연용 환자를 카드 리스트로 보여주고, 상세 생체정보를 펼쳐서 확인할 수 있게 구성되어 있습니다.

주요 기능:
- 적용 환자 카드 리스트 표시
- 상태 배지 표시
- HR, RR, SpO2, Skin Temp 현재값 표시
- 배터리 상태 표시
- 신호 상태 표시
- 상세 보기 펼침/닫기
- ECG 시뮬레이션 파형 확인
- Vital Signs History 그래프 확인
- 알림 범위(Target) 조정
- 적용 기록 확인

상세 영역에서 확인 가능한 항목:
- 환자번호
- 적용 상태
- 적용 시점
- 적용 사유
- 최근 알람
- ECG 그래프
- 활력징후 추세 그래프

주의:
- 화면 상단과 차트에는 DEMO DATA 성격의 안내가 포함됩니다.
- 실제 환자 데이터가 아니며, 실제 의료 판단용 화면이 아닙니다.


5. 더미 이상 징후 시연
----------------------
적용 환자 현황 탭에는 더미 이상 징후 시연 모드가 포함되어 있습니다.

주요 기능:
- 일부 환자에 대해 이상 징후처럼 보이는 수치 변동 표시
- 환자 카드 경고 강조
- 확인 완료 처리
- 일정 시간 동안 경고 억제 후 재노출

용도:
- 발표나 프로토타입 시연에서 "환자 상태를 확인하세요" 흐름을 보여주기 위한 기능입니다.


6. 초기 세팅
-------------
초기 세팅 탭은 HiCardi 적용 전 준비 과정을 단계형 체크리스트로 보여줍니다.

주요 기능:
- 환자명 또는 이니셜 입력
- 등록번호 또는 임시 ID 입력
- 병실 / 침상 입력
- 수술 후 경과일(POD) 입력
- 적용자 이름 또는 이니셜 입력
- 상태 메모 입력
- 이식 종류 선택
- 단계별 완료 체크
- 세팅 완료 후 시연용 환자 추가

단계 예시:
- 환자 확인
- 적용 기준 체크리스트 확인
- 피부 상태 확인
- 기기 번호 확인
- 기기 배터리 확인
- 패치 부착
- 환자-기기 매칭
- EKG / HR / RR 표시 확인
- 알람 상태 확인
- 적용 시작 시간 기록

세팅 완료 시:
- 시연용 환자가 적용 환자 현황 탭에 반영됩니다.
- 실제 서버 저장이 아니라 로컬 상태 기반으로 처리됩니다.


7. 간단 매뉴얼
---------------
간단 매뉴얼 탭은 HiCardi 사용 흐름을 단계별 아코디언 형태로 정리한 화면입니다.

주요 기능:
- 매뉴얼 검색
- 즐겨찾기
- 단계별 아코디언 열기/닫기
- PC / PDA 탭 전환
- 단계 이미지 확인

구성 예시:
- 전체 흐름
- Step 1. 솔루션 및 의료기기 준비하기
- Step 2. 환자·의료기기·수신기 매핑하기
- Step 3. 환자에게 의료기기 적용하기
- Step 4. 생체정보 실시간 관찰하기
- Step 5. 의료진 상의 후 매핑 해제 및 모니터링 종료하기

주의:
- 매뉴얼은 임시안입니다.
- 실제 적용, 해제, 종료 시점은 담당 의료진과 상의하는 흐름으로 안내합니다.


8. Q&A
------
Q&A 탭은 자주 묻는 질문과 고객센터 안내를 함께 제공합니다.

포함 내용:
- 고객센터 연락처
- 문의 가능 시간
- 카카오톡 QR 이미지
- 검색 가능한 FAQ 리스트

질문 예시:
- 환자 침상 또는 병실이 바뀌었더니 정보가 잘 끊기는 것 같아요.
- 검사실 이동 시 기기는 어떻게 하나요?
- 라이브스튜디오에서 심전도 그래프가 보이지 않고 맥박수만 보여요.
- 기기매핑관리 화면 목록에서 입원 환자가 보이지 않아요.
- 알람이 너무 자주 울리는데 설정 변경이 가능한가요?
- 기기 관리번호를 보여주는 QR이 떨어졌어요. 어떻게 하나요?

주의:
- FAQ 답변도 실제 임상 지시가 아니라 참고용 시연 문구입니다.
- 실제 대응은 담당 의료진, 병동 프로토콜, 제조사 지침을 우선합니다.


9. 판단 문구 원칙
-----------------
현재 main 버전에서는 사용자에게 보이는 문구를 다음 원칙으로 정리했습니다.

- HiCardi 적용 여부는 간호사가 단독 결정하지 않습니다.
- 적용 시작, 유지, 중단, 해제 시점은 담당 의료진과 상의하는 흐름으로 표시합니다.
- "보고" 중심 표현보다 "담당 의료진과 상의" 중심 표현을 사용합니다.

예시:
- HiCardi 적용 상의 필요
- HiCardi 적용 상의 권고
- 의료진 상의 필요
- HiCardi 중단 여부 상의
- 즉시 의료진 상의 필요


10. 더미 데이터와 안전 고지
---------------------------
이 앱은 프로토타입입니다.

반드시 유의할 점:
- 실제 EMR과 연결되지 않습니다.
- 실제 HiCardi 기기와 연결되지 않습니다.
- 실제 환자 개인정보를 저장하지 않습니다.
- 실제 생체정보를 수집하지 않습니다.
- 화면에 표시되는 수치와 그래프는 모두 시연용 더미 데이터입니다.
- 실제 임상 판단, 진단, 처방, 중단 결정을 대체하지 않습니다.


11. 실행 방법
-------------
개발 서버 실행:

  npm start

웹 실행:

  npm run web

정적 웹 빌드:

  npm run build:web

빌드 결과 확인:

  npm run serve:dist

타입 체크:

  npm run typecheck


12. 기술 스택

13. 배포 참고
-------------
