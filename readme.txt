Your_Cadi 앱 가이드
===================

1. 앱 개요
----------
Your_Cadi는 병동 간호사가 HiCardi 적용 판단 흐름을 시연하고, 적용 환자 현황과 매뉴얼, FAQ를 한 화면에서 빠르게 확인할 수 있도록 만든 Expo 기반 프로토타입 앱입니다.

이 앱은 실제 HiCardi 기기, 실제 EMR, 병원 서버와 연결되지 않습니다. 화면에 표시되는 환자 정보와 생체정보는 모두 시연용 더미 데이터이며, 실제 임상 판단·진단·처방을 대체하지 않습니다.


2. 현재 탭 구성
---------------
앱은 하단 탭으로 이동합니다.

- 적용 평가
- 환자 현황
- 매뉴얼
- FAQ


3. 적용 평가
------------
적용 평가는 단계형 화면으로 구성됩니다.

진행 순서:
- 1단계: 환자번호 검색
- 2단계: EMR 더미 환자정보 확인
- 3단계: NEWS2 자동 계산과 병동 특수 기준 확인
- 4단계: HiCardi 적용 판단 결과 확인

주요 기능:
- 환자번호 검색
- 더미 EMR 환자 정보 표시
- 최근 활력징후 기반 NEWS2 자동 계산
- 8A 병동 HiCardi 적용 판단 로직 표시
- 병동 특수 적용 기준 선택
- 평가 결과 카드 표시
- 평가 기록 저장
- 적용 후보 환자를 환자 현황 목록에 반영

사용 방법:
1. 환자번호를 입력하고 검색합니다.
2. 환자 요약 카드와 최근 V/S를 확인합니다.
3. 필요 시 상세 EMR 정보를 펼쳐 확인합니다.
4. 하단의 "HiCardi 적용 사정 시작하기" 버튼을 누릅니다.
5. NEWS2 총점과 병동 특수 적용 기준을 확인합니다.
6. 결과 카드에서 최종 판단과 다음 재평가 기준을 확인합니다.
7. 필요 시 적용 후보 저장 또는 평가 기록 저장을 선택합니다.


4. 환자 현황
------------
환자 현황은 적용 중 환자를 카드 목록으로 보여주고, 필요한 경우만 상세 정보를 펼쳐 확인하는 구조입니다.

카드에 기본 표시되는 정보:
- 환자명
- 병실/침상
- 상태 배지
- 연결 상태
- 배터리
- 현재값 4개: HR, RR, SpO2, Skin Temp

상세 영역에서 확인 가능한 항목:
- 현재 생체정보
- ECG 시뮬레이션 그래프
- Vital Signs History 그래프
- 알림 범위 설정
- 적용 기록 보기

주요 기능:
- 환자 카드 펼침/접힘
- ECG 더미 애니메이션 그래프
- Vital Signs History 그래프
- 그래프 tooltip
- 환자별 알림 범위(Target) 조정
- 적용 기록 확인


5. 개발용 데모 이상 징후 기능
------------------------------
환자 현황 화면에는 개발용 데모 이상 징후 토글이 있습니다.

토글 ON:
- 무작위 환자에게 이상 징후 더미 데이터가 적용됩니다.
- 이름 영역과 이상 수치가 강조됩니다.
- "환자 상태를 확인하세요" 알림이 표시됩니다.

토글 OFF:
- 생체정보가 정상 더미 데이터로 복귀합니다.
- 알림 억제 상태가 초기화됩니다.

"확인했습니다" 버튼:
- 해당 환자의 데모 알림 깜빡임을 10분간 중지합니다.
- 10분이 지나고 이상 수치가 유지되면 다시 알림이 나타날 수 있습니다.


6. 매뉴얼
---------
매뉴얼 탭은 HiCardi 운영 흐름을 접이식 항목으로 정리한 화면입니다.

주요 기능:
- 매뉴얼 검색
- 즐겨찾기
- 아코디언 펼침/접힘
- 단계별 이미지 보기

구성 예시:
- 전체 흐름
- Step 1. 솔루션 및 의료기기 준비
- Step 2. 환자·의료기기·수신기 매핑
- Step 3. 환자에게 의료기기 적용
- Step 4. 생체정보 실시간 관찰
- Step 5. 매핑 해제 및 모니터링 종료

사용 방법:
1. 검색창에서 원하는 키워드를 입력합니다.
2. 자주 보는 항목은 별표로 즐겨찾기합니다.
3. 필요한 단계 제목을 눌러 내용을 펼쳐 확인합니다.


7. FAQ
------
FAQ 탭은 자주 묻는 질문과 고객센터 정보를 함께 제공합니다.

상단 정보:
- People & Technology 고객센터
- 고객센터: 010-2280-3601
- 문의 가능 시간: 09:00 ~ 18:00
- 카카오톡 문의 QR

주요 기능:
- FAQ 검색
- 질문 아코디언 펼침/접힘
- 자주 사용하는 질문 우선 정렬

예시 질문:
- ECG 그래프가 보이지 않아요
- 환자가 목록에 보이지 않아요
- 알람이 너무 자주 울려요
- 검사실 이동 시 어떻게 하나요


8. 더미 데이터와 안전 고지
--------------------------
이 앱은 시연용 프로토타입입니다.

반드시 유의할 점:
- 실제 EMR과 연결되지 않습니다.
- 실제 HiCardi 기기와 연결되지 않습니다.
- 실제 환자 데이터를 저장하거나 표시하지 않습니다.
- 표시되는 생체정보는 모두 더미 데이터입니다.
- 실제 임상 판단을 대체하지 않습니다.


9. 웹 실행 및 빌드
-----------------
개발 서버 실행:

  npm run web

웹 정적 빌드:

  npm run build:web

빌드 결과는 dist 폴더에 생성됩니다.

로컬에서 dist 확인:

  npm run serve:dist

개발 서버 기본 주소 예시:

  http://localhost:8081


10. Vercel 배포
---------------
Vercel 설정 파일은 vercel.json입니다.

설정 요약:
- buildCommand: npm run build:web
- outputDirectory: dist
- devCommand: npm run web
- 모든 경로는 SPA 방식으로 "/"에 rewrite

GitHub 저장소를 Vercel에 연결하면 main 브랜치 push 후 Expo Web 빌드를 실행하고 dist 폴더를 배포할 수 있습니다.
